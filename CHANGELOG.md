# Change Log

All notable changes to the "tokenlens-monitor" extension will be documented in this file.

## [0.1.0] - 2026-06-10

### Added
- Initial release of TokenLens Monitor.
- Support for DeepSeek and Kimi balance queries.
- HTTP interception for automatic usage tracking (DeepSeek, OpenAI, Anthropic, etc.).
- Local log parsing for Continue, Cline, Aider, and other AI tools.
- Visual dashboard with trend charts, heatmaps, and model distribution.
- Status bar integration showing real-time account balance.
- Custom pricing support and cache hit rate analysis.
